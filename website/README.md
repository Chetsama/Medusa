# Photography Portfolio Website

This is a responsive photography portfolio website with a carousel component.

## Features

- Responsive design that works on mobile and desktop
- Photo carousel with navigation controls
- Dark/light theme toggle
- Gallery section with image overlays
- Smooth animations and transitions

## Structure

- `index.html` - Main homepage with carousel
- `gallery.html` - Gallery page with image grid
- `contact.html` - Contact form page
- `styles.css` - All styling
- `script.js` - JavaScript functionality
- `theme-init.js` - Theme initialization

## Carousel Component

The carousel features:
- Automatic slide advancement every 5 seconds
- Manual navigation with arrow buttons
- Indicator dots for slide selection
- Responsive design that adapts to screen size
- Smooth fade transitions between slides

## Setup

1. Clone the repository
2. Open `index.html` in a web browser
3. The site will work immediately with no additional setup required

## Customization

To customize the carousel:
1. Add/remove images in the `images/` folder
2. Update the HTML in `index.html` to match your image count
3. Modify CSS in `styles.css` for different styling
4. Adjust JavaScript in `script.js` for different behavior

## Dependencies

- Pure HTML/CSS/JavaScript (no external libraries)
- Modern browser support (Chrome, Firefox, Safari, Edge)
